
# Area

Интерактивные карты помещений с привязкой 360°-панорам (MVP).

## Стек

- **Frontend:** React 19 + TypeScript + Vite, Tailwind CSS v4, react-router-dom v7
- **Backend:** Python + FastAPI
- **Хранение:** проекты — JSON-файлы; планы и панорамы — локальные папки
- **Карта:** SVG · **Панорамы:** Pannellum · **Офлайн:** Service Worker + Cache Storage + IndexedDB
- SQL-базы не используются

## Запуск всего стека через Docker

```bash
# Скопируйте пример переменных
cp .env.example .env

# Собрать и поднять фронтенд + бэкенд
docker compose up --build -d

# Фронтенд: http://localhost:3000
# Бэкенд API: http://localhost:8000
# Прокси через nginx: http://localhost:3000/api/...
```

Остановить:
```bash
docker compose down
```

## Запуск фронтенда (разработка, без Docker)

```bash
cd frontend
npm install          # один раз
npm run dev          # http://localhost:5173
npm run build        # сборка в dist/
npm run preview      # предпросмотр сборки
npm run lint         # ESLint
```

## Запуск бэкенда (разработка, без Docker)

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

## API-контракт

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/projects` | Список проектов |
| POST | `/api/projects` | Создать проект |
| GET | `/api/projects/{id}` | Загрузить проект |
| PUT | `/api/projects/{id}` | Сохранить проект |
| DELETE | `/api/projects/{id}` | Удалить проект |
| POST | `/api/projects/{id}/files` | Загрузить план или панораму (в разработке) |
| GET | `/api/projects/{id}/files` | Список файлов проекта (в разработке) |
| GET | `/api/files/{file_id}` | Скачать файл (в разработке) |

## Авторизация (MVP, без бэкенда)

- `/auth` — вход / регистрация (данные хранятся в `localStorage`)
- `/profile` — профиль пользователя (доступен после входа)
- Пароль минимум 6 символов, email с `@`

## Что сделано (фронт)

В «Моих проектах» карты и Workspace отображаются общими карточками с фильтрами.
Workspace создаются через общую форму «Создать проект» с выбором типа.
На странице `/workspace/:workspaceId` доступен 2D-холст карт:
переименование, независимое размещение карт и объединение в перемещаемые
контейнеры. Workspace сохраняются в браузере; объединённые карты сохраняют связь
с исходными проектами, 2D-редактором и панорамами.

В редакторе инструменты, метки, сетка и масштаб расположены слева,
свойства и список объектов — справа. Верхняя панель содержит навигацию и переключатель 2D/3D.
Доступны фигуры по образцу Paint и редактирование вершин с отменой / возвратом.
Многоугольник строится по точкам до замыкания на первой вершине. Ctrl + A выделяет
все видимые объекты редактора или карты активного Workspace.

«Открыть карту» ведёт в 2D-редактор для пустого проекта, в Pannellum 360° при
наличии панорамы или на 2D-карту при наличии только плана / чертежа.
Сохранённый чертёж служит основой для точек с панорамами; готовый план можно
загрузить изображением. Режимы 2D и 3D переключаются из карты и просмотра.
Pannellum устанавливается через npm и входит в сборку, подключение к CDN не требуется.
