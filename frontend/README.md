# Frontend Area

React 19, TypeScript, Vite и Tailwind CSS. Интерфейс оформлен в палитре ТТК.

## Палитра ТТК

Источник: [официальные материалы ТТК](https://company.ttk.ru/logo/).
Основные цвета взяты из опубликованного SVG: красный `#DD2538` и графитовый `#1A1B1B`.
Светлые фоны, оттенки для наведения и границы дополняют эту палитру в интерфейсе.
Цвета определены в `src/index.css` через переменные `--ttk-*` и семантические
утилиты Tailwind: `brand`, `brand-hover`, `brand-soft`, `ink`, `body`, `muted`,
`page`, `surface-muted`, `line`. SVG-редактор использует те же переменные.
Официальный логотип хранится локально в `public/ttk-logo.svg`.

## Редактор чертежей

Выберите инструмент и протяните указатель по холсту, чтобы создать фигуру. По умолчанию
ячейка сетки равна 0,5 м (25 px при масштабе 100%); каждое пятое деление выделено.
Ctrl + колесо над холстом меняет масштаб от 25% до 400% относительно курсора.
Масштаб также можно ввести числом в процентах, применив его Enter или выходом из поля.
Сетка и фигуры масштабируются вместе. Зажатое колесико мыши позволяет перетаскивать
холст; прокрутка двумя пальцами на тачпаде перемещает его по обеим осям.
Навигация действует только над холстом.

Для растягивания выделенной фигуры перетащите любой угловой маркер; у линий и размеров
можно двигать концы. Противоположный угол остается на месте. Shift включает привязку
к углам и концам других фигур. Отдельный инструмент квадрата удалён, сохранённые
ранее квадраты продолжают открываться.

Ctrl + Z (также Cmd + Z) или кнопка «Отменить» возвращает до 100 последних изменений:
создание, перемещение, растягивание, свойства и удаление. Один жест — одно действие.
Ctrl + Y (также Cmd + Y) или кнопка «Вернуть» под кнопкой отмены повторяет отменённые
изменения. Новое изменение после отмены очищает историю возврата.
В текстовых и числовых полях сохраняется обычная отмена ввода. Escape отменяет текущий
жест. История действует до закрытия редактора; чертежи, включая результат отмены,
сохраняются в проекте в localStorage.

Проверки:

```powershell
npm.cmd run build
npm.cmd run lint
# Однократно, если Chromium ещё не установлен:
npx.cmd playwright install chromium
npm.cmd run test:e2e
# Или использовать установленный Microsoft Edge:
$env:PLAYWRIGHT_CHANNEL = 'msedge'
npm.cmd run test:e2e
```
