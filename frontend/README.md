# Frontend Area

React 19, TypeScript, Vite и Tailwind CSS. Интерфейс оформлен в палитре ТТК.

## Палитра ТТК

Источник: [официальные материалы ТТК](https://company.ttk.ru/logo/).
Основные цвета взяты из опубликованного SVG: красный `#DD2538` и графитовый `#1A1B1B`.
Светлые фоны, оттенки для наведения и границы дополняют эту палитру в интерфейсе.
Цвета определены в `src/index.css` через переменные `--ttk-*` и семантические
утилиты Tailwind: `brand`, `brand-hover`, `brand-soft`, `ink`, `body`, `muted`,
`page`, `surface-muted`, `line`. SVG-редактор использует те же переменные.
Официальный логотип хранится локально в `public/ttk-logo.svg`.

### Тёмная тема

Переключатель в шапке и на странице входа; выбор хранится в `space-map-theme`,
при первом визите берётся системная тема. Тема задаётся атрибутом `data-theme`
на `<html>`: те же токены `--ttk-*` получают тёмные значения, поэтому компоненты
используют семантические классы (`bg-surface`, а не `bg-white`). Красный в тёмной
теме чуть светлее (`#E8364A`), чтобы и текст, и кнопки сохраняли контраст.
Логотип для тёмной темы — `public/ttk-logo-dark.svg` (светлые буквы, красный знак).

## Роли, вход и профиль

Аккаунты пока хранятся в браузере (`space-map-accounts`), серверный API не подключён.
Пароли сохраняются только как SHA-256 с солью и повторами (`utils/sha256.ts` — без
`crypto.subtle`, чтобы работать и по HTTP). Демо-доступ: администратор
`demo@spacemap.ru` / `SpaceMap123!`, пользователь `user@spacemap.ru` / `Viewer123!`.

- **Регистрация** на `/login` создаёт обычного пользователя.
- **Пользователь** видит список объектов (`/`) и открывает их только для просмотра:
  `/objects/:id?mode=2d|3d` — план с точками и метками, панорамы 360°, переход
  по навигационным меткам. Редактор, проекты, Workspace и статистика ему недоступны.
- **Администратор** работает с проектами, как раньше, и видит статистику.
- **Профиль** (`/profile`): имя, смена почты и пароля (с текущим паролем), аватар
  с кадрированием под круглой маской (256×256 JPEG).

## Статистика

Посещения страниц, нажатия кнопок и открытия панорам записываются автоматически
(`components/AnalyticsTracker.tsx`, `utils/analytics.ts`, журнал `space-map-analytics`,
до 5000 событий). Источник перехода: кнопка внутри сайта, прямая ссылка, внешний сайт
или `?utm_source=…`; клики и панорамы относятся к источнику входа в сессию.
Страница `/stats` — общие метрики, посещаемость по дням, источники, кнопки, рейтинг
проектов и самые активные посетители; фильтры по периоду, источнику, роли и проекту.
`/stats/:id` (ссылка «Посмотреть статистику» на карточке) добавляет долю проекта
от всех проектов и его место. Для демонстрации есть генерация демо-данных за 30 дней.

## Превью проектов

Обложка карточки показывает содержимое проекта: первую доступную панораму (фото),
затем загруженный план, а если изображений нет — сохранённый чертёж. При возврате
к списку проектов обложки загружаются заново. Повреждённые изображения пропускаются.
Для изображений создаётся миниатюра 640 × 360; исходные файлы сохраняются без изменений.
План показывается целиком, фото заполняет обложку, чертёж вписывается по границам фигур.

## 2D Workspace

Карты и Workspace показываются одинаковыми карточками в «Моих проектах».
Фильтр «Все / Карты / Workspace» меняет тип отображаемых карточек. Чтобы создать
Workspace, откройте общую форму «Создать проект» и выберите тип «Workspace».
Создание убрано со страницы холста. Карточка открывает `/workspace/:workspaceId`;
пункт меню `/workspace` открывает последний активный Workspace. Можно создать
несколько Workspace, переименовывать, переключать и удалять их. У каждого свой
набор карт, расположение контейнеров и масштаб. Одну карту можно добавить в разные
Workspace через список «Все карты».

Перетаскивайте карту за заголовок; Shift / Ctrl + клик, флажки на картах или рамка
на свободном месте выбирают несколько карт. Кнопка «Объединить» помещает их в общий
контейнер: карты перемещаются вместе, сохраняя взаимное расположение. Контейнер
можно назвать, дополнить другими картами или разделить кнопкой «Разделить».
Объединение сохраняет исходные карты отдельными проектами, с их чертежами и панорамами.
Delete / «Убрать из Workspace» убирает карту из текущего Workspace.

Колесико мыши и жест двумя пальцами перемещают холст, Ctrl + колесо меняет масштаб
относительно курсора; также доступны числовой масштаб 25–200%, «Вписать всё» и
привязка к сетке. Ctrl + Z / Ctrl + Y отменяют и возвращают добавление, удаление,
перемещение и объединение контейнеров. Escape отменяет незавершённое перетаскивание
или выделение. Ctrl + A выделяет все карты активного Workspace. Превью в Workspace показывает 2D-план / чертёж. Из карты можно открыть
её 2D-страницу или редактор, а затем вернуться в Workspace.

Workspace сохраняются локально в `space-map-workspaces`; чертежи, точки и файлы
продолжают храниться в соответствующих проектах. Удаление Workspace сохраняет карты.

## Открытие карты и панорамы

Кнопка «Открыть карту» открывает 2D-редактор, если проект ещё не содержит плана,
чертежа или панорам. Из редактора кнопка «2D-карта и панорамы» ведёт к карте:
на сохранённом чертеже можно ставить точки так же, как на загруженном изображении.
Там же можно загрузить план вместо рисования. Если есть изображение плана,
оно используется как основа карты; иначе показывается сохранённый чертёж.

Если у точек есть панорамы, при обычном открытии карты запускается первая из них.
Если панорам ещё нет, открывается 2D-карта с возможностью их загрузки.
Переключатель 2D/3D в верхней панели переключает карту и Pannellum; до загрузки
панорамы режим 3D недоступен. `?mode=2d` открывает карту сразу в 2D.
Верхняя панель также содержит возврат к проекту, название, переход к карте
и связанному Workspace, если карта добавлена в него.

Просмотр 360° использует **Pannellum 2.5.7** через JavaScript API. Библиотека и CSS
поставляются вместе со сборкой, без обращения к CDN. Для загрузки используйте
сферические панорамы в эквидистантной проекции (обычно изображение 2:1).
В просмотре доступны осмотр мышью / касанием, масштабирование, сброс вида,
выбор другой панорамы и возврат к карте по Escape. Ошибки чтения изображения
и отсутствие WebGL не блокируют возврат в 2D и замену файла. При закрытии
просмотра освобождается экземпляр Pannellum; при уходе с карты — ссылки на изображения.

Документация: [Pannellum API](https://pannellum.org/documentation/api/),
[параметры](https://pannellum.org/documentation/reference/).

### Панорамы навигационных меток

У навигационной метки редактора может быть своя панорама: в свойствах метки её можно
создать, открыть, заменить, пересобрать из фото и удалить (с подтверждением).
Двойной клик по метке открывает её панораму, а без панорамы — карту из «Переход на карту».
В просмотре можно переключаться между панорамами всех навигационных меток этажа.
Файл хранится в IndexedDB по ключу `panorama:${storageId}:${id метки}`.

### Панорама из нескольких фото

Кнопки «Собрать из фото» у навигационной метки и «Собрать из нескольких фото» у точки
2D-карты открывают окно склейки: подсказки по съёмке, схема кадров по кругу, превью
снимков и проверки (минимум 2, рекомендуется 8–12, одна ориентация). Склейку выполняет
backend (`POST /api/panoramas/stitch`, OpenCV): находит общие детали кадров, оценивает
поворот камер и возвращает равнопромежуточную панораму 2:1 для Pannellum вместе
с охватом и номерами вошедших снимков. По ним окно подсказывает, не замкнут ли круг,
сняты ли пол и потолок и какие кадры не удалось связать.

Для склейки нужен запущенный backend на `:8000`; dev-сервер Vite проксирует к нему `/api`:

```powershell
cd backend
python -m pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

## Этажи

В верхней панели между связанным Workspace и переключателем 2D/3D находится
кнопка «Этаж». По умолчанию существует этаж «1»; прежние чертежи, планы и панорамы
остаются на нём. Новые этажи получают номера «2», «3» и далее. Клик по названию
в списке переключает этаж, карандаш справа позволяет переименовать его
(Enter или выход из поля сохраняет название, Escape отменяет ввод).

Внизу списка расположены «Добавить этаж» и под ней «Удалить этаж».
Удаление требует подтверждения в окне сайта и удаляет чертёж, точки, план и панорамы выбранного
этажа. Единственный оставшийся этаж удалить нельзя. Данные остальных этажей
сохраняются. У каждого этажа свой чертёж, план, метки и панорамы; переключение
работает и в 2D, и в Pannellum. История отмены начинается заново при смене этажа.
Выбранный этаж сохраняется в проекте и учитывается в превью карточек и Workspace.
Ссылка с `?floor=<id>` открывает конкретный этаж.

## Инструменты 2D-редактора

Удаление проектов, Workspace, этажей, планов, точек и панорам подтверждается
в едином окне сайта. «Отмена», Escape или клик по затемнённому фону закрывают
окно без удаления. Фокус при открытии установлен на «Отмена»; Tab перемещается
только внутри окна.

Слева сверху вниз находятся инструменты, метки, настройки сетки и масштаба.
Справа — свойства выбранного объекта и ниже список всех объектов с выбором
по клику (Shift / Ctrl — несколько). На узком экране панели располагаются под холстом.

Добавлены эллипс, треугольник, ромб, пятиугольник, шестиугольник, звезда, стрелка,
многоугольник и ломаная. Фигуры, кроме многоугольника, создаются протягиванием.
Многоугольник строится кликами по вершинам и завершается кликом по первой точке.
До замыкания черновик не сохраняется. Необходимо минимум три не лежащие на одной
прямой вершины. Во время построения рядом с рёбрами показываются их длины в метрах,
включая текущий отрезок до курсора. После замыкания или отмены подписи исчезают.
Ctrl + Z убирает последнюю точку черновика, правая кнопка мыши, Escape или смена
инструмента отменяют построение. Замкнутый многоугольник — одно действие в истории.
Новые фигуры сохраняются в проекте и отображаются в карте, карточках и Workspace.

Инструмент «Вершины» показывает редактируемые вершины выбранной фигуры.
Их можно перетаскивать с привязкой, добавлять двойным кликом по ребру или кнопкой
«Добавить вершину» в свойствах, удалять кнопкой «Удалить вершину» или Delete.
Прямоугольник при изменении вершин становится многоугольником, линия — ломаной.
У замкнутой фигуры остаётся минимум 3 вершины, у открытой — 2.
У эллипсов вершины не редактируются; меняются размеры. Изменения вершин участвуют
в Ctrl + Z / Ctrl + Y, Escape отменяет незавершённое перетаскивание.

Метки создаются кликом: информационные (название и описание), навигационные
(переход на другую карту), статусные («Готово», «В работе», «Недоступно»).
На 2D-карте метка открывает описание или переводит на выбранную карту.
В редакторе навигационная метка открывается двойным кликом.
Служебные метки доступны в палитре редактора. Их выбор автоматически включает слой
«Показывать служебные метки». Слой можно включать и выключать в настройках;
в обычной карте и превью служебные метки всегда скрыты.

Ctrl + A (также Cmd + A) выделяет все видимые объекты и переключает на «Выделение».
Незавершённый черновик при этом отменяется. Скрытые служебные метки не выделяются.
В текстовых и числовых полях сочетание сохраняет обычное выделение текста.

Выберите инструмент и протяните указатель по холсту, чтобы создать фигуру. По умолчанию
ячейка сетки равна 0,5 м (25 px при масштабе 100%); каждое пятое деление выделено.
Ctrl + колесо над холстом меняет масштаб от 25% до 400% относительно курсора.
Масштаб также можно ввести числом в процентах, применив его Enter или выходом из поля.
Сетка и фигуры масштабируются вместе. Зажатое колесико мыши позволяет перетаскивать
холст; прокрутка двумя пальцами на тачпаде перемещает его по обеим осям.
Навигация действует только над холстом.

В инструменте «Выделение» Shift + левый клик добавляет объект к выделению,
повторный Shift + клик по нему снимает выделение. Shift + клик по свободному месту
сохраняет выбранную группу. Выбор не меняет чертёж и историю отмены.
В инструментах рисования Shift продолжает включать привязку к фигурам,
а на маркере поворота задаёт шаг 15°.

Также для выделения нескольких объектов нажмите левую кнопку дважды, удерживайте второе
нажатие и протяните рамку по холсту. Выделяются фигуры, пересекающие рамку; обычный
двойной клик без протягивания выбирает один объект. Жест доступен из инструментов рисования
и переключает редактор на «Выделение». Группу можно перемещать за любую выбранную
фигуру или удалить кнопкой «Удалить выбранные» либо клавишей Delete; Ctrl + Z / Ctrl + Y отменяет и возвращает
изменение всей группы одним действием. Escape отменяет рамку.

Инструмент «Линейка» измеряет расстояние между двумя точками. Правая кнопка мыши
отменяет незавершённое измерение. После построения правый клик по свободному месту
при активной «Линейке» убирает выделенную линейку; правый клик по самой линейке
также удаляет её. Удаление можно отменить через Ctrl + Z.

Для растягивания выделенной фигуры перетащите любой угловой маркер; у линий и линеек
можно двигать концы. Противоположный угол остается на месте. Shift включает привязку
к углам и концам других фигур. Отдельный инструмент квадрата удалён, сохранённые
ранее квадраты продолжают открываться.

Над выбранным объектом или группой появляется круглый маркер поворота, соединённый
с рамкой. Зажмите его левой кнопкой мыши и перетаскивайте: объект вращается вокруг
своего центра, группа — вокруг общего центра с сохранением взаимного расположения.
Shift задаёт шаг 15°. Когда маркер в фокусе, стрелки ← / → поворачивают на 1°,
со Shift — на 15°. Escape или Ctrl + Z во время жеста отменяют незавершённый поворот.
Завершённый поворот — одно действие в истории Ctrl + Z / Ctrl + Y.
Угол сохраняется в проекте и учитывается на карте, в превью и Workspace.
Тип фигуры и её собственные размеры сохраняются; углы и вершины можно редактировать
и после поворота.

Ctrl + Z (также Cmd + Z) или кнопка «Отменить» возвращает до 100 последних изменений:
создание, перемещение, растягивание, свойства и удаление. Один жест — одно действие.
Ctrl + Y (также Cmd + Y) или кнопка «Вернуть» под кнопкой отмены повторяет отменённые
изменения. Новое изменение после отмены очищает историю возврата.
Delete удаляет один выделенный объект или всю выделенную группу.
В текстовых и числовых полях сохраняются обычная отмена ввода и удаление символов. Escape отменяет текущий
жест. История действует до закрытия редактора; чертежи, включая результат отмены,
сохраняются в проекте в localStorage.

Проверки:

```powershell
npm.cmd run build
npm.cmd run lint
# Однократно, если Chromium ещё не установлен:
npx.cmd playwright install chromium
npm.cmd run test:e2e
# Или использовать установленный Microsoft Edge:
$env:PLAYWRIGHT_CHANNEL = 'msedge'
npm.cmd run test:e2e
```
